## 규칙

w는 주(금요일로 끝나는 주), close[w]는 그 주 마지막 거래일 종가(배당 미포함 가격)입니다.

- **이동평균:** SMA[w] = mean(close[w-9], ..., close[w])
- **기본 신호:** m[w] = 1 if close[w] > SMA[w] else 0 (10주 단독과 같음)
- **기울기:** d[w] = SMA[w] − SMA[w-1]. d > 0이면 상승 중, d < 0이면 하락 중.
  - 10주 이동평균에서 d[w] = (close[w] − close[w-10]) / 10 이므로, "상승 중"은 "이번 주 종가가 10주 전 종가보다 높다"와 같습니다.

**보유 상태 (주마다 갱신)**

| 지난주 상태 | 이번 주 조건 | 이번 주 상태 |
|---|---|---|
| 현금 | m = 1, d ≥ 0 | 주식 (매수) |
| 현금 | m = 1, d < 0 | 현금 (하락 중이라 매수 금지) |
| 현금 | m = 0 | 현금 |
| 주식 | m = 0, d ≤ 0 | 현금 (매도) |
| 주식 | m = 0, d > 0 | 주식 (상승 중이라 매도 금지) |
| 주식 | m = 1 | 주식 |

- 이동평균과 기울기가 모두 처음 나오는 주에는 m[w]로 시작하고, 그 뒤로 매주 갱신합니다.
- **실행:** 신호를 낸 날(그 주 마지막 거래일)의 **다음 거래일 종가**에 체결합니다. 체결일 하루의 수익률은 체결 전 상태에 귀속합니다.
- **비중:** 100% 주식 또는 100% 현금. **확인 주기:** 주 1회.
- **비교 대상:** 단순 보유(평가 시작 전날 종가에 매수), 10주 이동평균 단독. 같은 기간, 같은 비용·세금.

## 판단 기준 (결과를 보기 전에 정함)

두 자산을 따로 판단합니다. 숫자는 [ADX 매도 필터 실험](2026-11-02-sma10w-adx-exit-spy.md)에서 사용자가 확인한 기준을 그대로 씁니다. 고정 비중 비교는 이번에 하지 않습니다.

1. 세후 기준으로 아래 둘 중 하나를 충족합니다.
   - (가) 샤프가 단순 보유보다 높다.
   - (나) 청산 후 CAGR이 단순 보유보다 1%p 이내로 낮고, MDD가 단순 보유보다 15%p 이상 작다.
2. 이동평균 8~15주, 기울기 간격 1~4주에서 1의 결론이 뒤집히지 않습니다.
3. 신호 요일과 하위 기간은 통과 여부를 정하는 데 쓰지 않고, 1~2를 통과했을 때 근거가 약한지 판단하는 데 씁니다. 요일 5개 중 과반에서 1을 넘지 못하면 "보류"로 둡니다.

설계용 기간에서 통과하면 검증 에이전트의 확인과 사용자 확인을 받은 뒤 표본 외 기간을 한 번 봅니다. 통과하지 못하면 표본 외 기간은 보지 않습니다.

## 엔진 검사 (테스트)

- **상태 전이:** 하락 중 매수 금지, 상승 중 매도 금지, 기울기 0이면 기본 신호, 준비 기간은 NaN
- **독립 구현 비교:** "기울기 상승 = 종가 > 10주 전 종가"로 따로 계산한 신호와 같은지
- **미래 정보 검사:** t 이후 가격을 바꿔도 t까지의 신호, 보유 상태, 수익률이 그대로인지
- **체결 시점:** 신호 낸 다음 거래일 종가에 체결되는지
- **무작위 보행 검사:** 추세 없는 가짜 가격에서 전략의 샤프가 단순 보유보다 뚜렷이 높으면 실패
- **합성 ETF:** KOSPI 실험 스크립트에 있던 합성 함수를 `src/`로 옮기면서 테스트를 붙입니다 (KOSPI ADX 실험 검증 7번 지적). 옮긴 뒤 이전 리포트가 똑같이 다시 만들어지는지 확인합니다.

## 검증 (backtest-reviewer, 2026-11-15)

결과를 좋거나 나쁘게 만드는 계산 버그는 찾지 못했습니다. 검증 에이전트가 데이터를 설계용 기간 끝에서 자른 뒤 정수 산술로 신호와 엔진을 따로 짜서, 기본 결과, 민감도, 하위 기간, 필터 효과, MDD 회복 기간을 모두 같은 값으로 재현했습니다. 표본 외 기간은 계산하지 않았습니다. 미래 정보, 준비 기간과 경계 규칙(기울기 0, 종가 = 이동평균), 합성 ETF 이전, 신호 요일, 하위 기간 처리, 차트 입력(기울기 칸과 신호 기울기의 부호 일치 포함)에도 문제가 없었습니다. 아래는 검증 에이전트의 지적과 수치입니다.

1. **[중간] 리포트 행 이름 오기.** 이동평균 기간 민감도 표의 단독 행 이름이 "N주, 10주 단독"으로 찍혀 있었지만 실제로는 N주 이동평균 단독입니다. 숫자는 맞았습니다. "N주, 이동평균 단독"으로 고치고 리포트를 다시 만들었습니다(행 이름 28개만 바뀜).
2. **[중간] SPY 세전 샤프 우위(0.36 대 0.34)는 잡음 수준입니다.**
   - 차이 +0.025에 대해 63거래일 블록 부트스트랩(2,000회)의 표준오차가 0.178입니다.
   - 한 해씩 빼고 계산하면 2008년을 뺄 때만 -0.13으로 뒤집힙니다. 다른 해는 -0.02 ~ +0.09입니다.

3. **[중간] 신호 요일이나 이동평균 기간 하나만 바꿔도 판정이 뒤집힙니다.**

   - 날 단위 t값은 자기상관을 무시하므로 실제 유의성은 더 약합니다. 표에 연 기여와 t값을 넣자는 제안은 **반영하지 않았습니다**.
7. **[낮음] 테스트 공백.** 독립 구현 비교 테스트는 10주, 간격 1주만 다룹니다. 검증 에이전트는 실제 데이터에서 5~40주, 간격 1·2·4주, 요일 5개를 따로 비교해 4번의 4건 말고는 일치함을 확인했습니다. 테스트 추가는 **하지 않았습니다**.

## 배운 것

- 기울기 필터는 매수와 매도를 모두 늦춥니다. SPY에서는 "늦게 판 것"이 상승장의 휩소를 줄여(예: 1999년 6월) 10주 단독보다 나아졌고, KOSPI에서는 같은 성질이 급락 뒤 빠른 반등(2001년 10~11월)과 하락 초입에서 손해가 되었습니다. 같은 규칙이 시장마다 반대로 작동했습니다.

- **경고:** 이번 민감도에서 좋아 보인 설정(SPY 40주 + 필터 세후 샤프 0.38, KOSPI 8주 + 필터 0.60)은 사전 범위 밖이거나 이웃 값과 들쭉날쭉하고, 두 자산에서 잘 되는 기간이 다릅니다. 이것으로 새 가설을 세우면 같은 설계용 기간을 세 번째로 쓰게 됩니다. 그렇게 한다면 새 일지에 이 사실을 먼저 적어야 합니다.
